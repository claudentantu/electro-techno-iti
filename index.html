À propos d'ÉLECTRO TECH

ÉLECTRO TECH est un projet éducatif destiné à aider les élèves à mieux comprendre les notions d'électronique.

École : ITI N'DJILI

Objectif : apprendre ensemble, partager les connaissances et réussir les exercices pratiques.

Ce site est un projet indépendant créé pour les élèves. Il ne s'agit pas d'un site officiel de l'établissement.
